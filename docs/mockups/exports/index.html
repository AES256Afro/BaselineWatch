Export templates: 10 mockups

Layouts for exporting a platform's baseline decisions and test plan to PDF, Word and Markdown. Same sample in each: macOS 26 Security Baseline and Test Report, 212 rules, 10 decisions shown, 24 test steps in 7 areas, 5 POA&M items. Print a page to PDF to see its paged layout.

Sample data. Mockup with sample data. Names, counts and evidence references are invented. DISA STIG and NIST content is public domain; recommendations are paraphrased. No CIS Benchmark text appears anywhere.

02Engineering runbookPlex Sans and Mono, each test a numbered step with a copy-ready command block and a tick box.

06Dark consoleMartian Mono on near-black, prompts and ASCII bars, test steps as a session transcript. Prints with a dark background.
07Jira / kanban cardsIssue cards with keys, priority, labels and assignee avatars. Decisions in three lanes, tests on a Pass / Fail / Other board.
08Audit workpaperWorkpaper header block, W/P references, tickmark legend and prepared / reviewed initials and dates on every row.
09Markdown-nativeRendered Markdown (GitHub style) beside the raw source. Raw file: 09-markdown-native.md.
10Word document (.docx)Letter pages on grey, Calibri-metric Carlito, Word’s built-in Heading and Grid Table styles, TOC with dot leaders, running header and footer.

Every template includes

  • Cover: platform, three standards with versions, date, version, prepared by, approval block
  • Executive summary: recommended / applied / modified / not applied; pass / fail / n/a / not tested
  • Decision register: publisher recommendation (STIG ID and CAT, mSCP rule, 800-53 controls) beside our decision, justification and owner
  • Test plan by area: procedure, expected result, result, evidence, tester
  • POA&M and exceptions; attribution footer

Formats

  • PDF: any template; each has @page size and margins and page breaks between sections
  • docx: 10 is the Word layout; 01 and 08 also convert to Word tables
  • Markdown: 09, with the raw file 09-markdown-native.md

Notes

  • Mockups use inline styles and Google Fonts; they are not served by the app, so the app's CSP does not apply.
  • 06 prints with a dark background; 04, 07 and 08 print landscape.
