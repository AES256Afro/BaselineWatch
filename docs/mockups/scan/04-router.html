Firmware has a known exploited vulnerability
CVE-2026-20142 (KEV, added 2026-09-30, due 2026-10-21): authentication bypass in the EX7000 web interface before 1.0.11.130. Your firmware is 1.0.11.116.
  • Vulnerabilities page: CVE-2026-20142 · CVSS 9.8 · EPSS 0.71 · KEV
  • Vendor advisory linked on the CVE's Fix panel; the fix is firmware 1.0.11.130 or later.
Why it matters. The router is the one device every other device trusts. A bypass on its admin page from the LAN side is reachable by any device that joins the network, including a guest's phone. More
Finding
02
UPnP port mappings exist
Three mappings were listed by the gateway's IGD service. Two name a games console; one, TCP 3389 to 192.168.8.44, is a remote-desktop port opened to the internet by something on that host.
  • UDP 3074 → 192.168.8.21 (Xbox) · UDP 3544 → 192.168.8.21 (Teredo) · TCP 3389 → 192.168.8.44 (unknown)
Why it matters. UPnP lets any program on the LAN open a hole in the firewall without asking. The remote-desktop mapping is a finding until the host that requested it is known; turning UPnP off on the router removes the mechanism. More
Finding
03
Admin page uses HTTPS and is LAN-only
Port 80 redirects to 443; the certificate is self-signed (expected on a home router); the WAN side does not answer on 80, 443 or 8443.
Pass
04
DNS handed out is your filtering resolver
DHCP offers 192.168.8.10 only, so devices that take DHCP use the Pi-hole. Devices with a hard-coded resolver bypass it; the firewall check tests whether the router lets them.
Pass
05
Default credentials not tested
This check never tries to sign in. Do it yourself, once: open the admin page and confirm the password is not the one printed on the router.
Manual Guide

How this was read

  • The gateway address and DNS come from this server's DHCP lease.
  • Model and firmware come from the UPnP device description (an XML the router serves on the LAN) and, where the router has one, its status page's title; nothing signs in.
  • Port mappings come from an SSDP search and the IGD GetGenericPortMappingEntry call, which any device on the LAN may make.
  • The firmware is matched against the CVE database by vendor and product, the way the Vulnerabilities page matches your watchlist.

Owner's choice

The router check is off until the owner turns it on in Settings, because it sends packets on the LAN. It runs daily once on, and alerts through the same channel as KEV additions when the router's firmware gains a KEV entry or a new port mapping appears.
