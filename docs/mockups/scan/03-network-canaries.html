This network canaries through the LAN resolver

The resolver the router hands out is 192.168.8.10 (Pi-hole). Forty-eight canary names in four categories were resolved through it from this server; a name that returns 0.0.0.0, NXDOMAIN or the sinkhole address is blocked for every device using that resolver. A phone on a VPN, or a browser with its own DNS-over-HTTPS, does not use it; the browser check catches those.

Who uses this resolver

The Pi-hole's query log over the last day shows 23 clients. Devices missing from it either use another resolver (a VPN, DNS-over-HTTPS in the browser, a hard-coded 8.8.8.8) or were off. The firewall check says whether the router lets DNS bypass the Pi-hole at all.

The canary lists

  • Ads and trackers: names chosen from EasyList and EasyPrivacy's most-matched rules, refreshed with the lists.
  • Malware and phishing: names from URLhaus and OpenPhish that are on the common DNS blocklists (Hagezi, OISD).
  • Ad-delivered spyware: the adfection list (291 reviewed domains from Citizen Lab, Confiant, Recorded Future, Microsoft, ESET, Avast, Google TAG and Amnesty reports), tracked in the Register as a source.
  • Control: a name that always resolves and names the upstream.

Canaries are resolved by this server only; no device of yours contacts them, and nothing is fetched from them.
