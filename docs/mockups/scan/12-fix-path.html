Give this browser a filtering resolver None seen

A blocker protects one browser; a filtering resolver answers for every app that uses the system DNS. Neither AdGuard DNS nor NextDNS answered here. A Pi-hole or Quad9 may still be filtering — they have no self-check; step 4 is their eye. Why it matters.

  1. Download the AdGuard DNS profile, or create a NextDNS profile (it names itself to the re-check).
  2. System Settings › Privacy & Security › Profiles › Install. On iPhone, Android and Windows: one page each.
How you'll know: the re-check asks the resolver to name itself; this row turns to the resolver's own answer, e.g. NextDNS · profile f3a9d1.
