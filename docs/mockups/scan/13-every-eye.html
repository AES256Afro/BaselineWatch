The router's firmware is on CISA's exploited list — CVE-2026-20142, due 21 Oct
EX7000 running 1.0.11.116, read from its UPnP description; the fixed build is 1.0.11.136. A router on the KEV list is the one device every other device trusts. This product never signs in to the router — updating is yours to do.

Finding
A UPnP mapping forwards TCP 3389 to a LAN device (.44)
Remote Desktop forwarded to a machine inside — a mapping some app asked for and nothing cleaned up. Not visible in the public index today, which proves nothing about tomorrow.
The fix Delete the mapping in the router's admin page (two clicks; the guide shows this model) or turn UPnP off entirely — what that trades away.
