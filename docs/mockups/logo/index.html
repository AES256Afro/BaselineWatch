Logo and favicon: 20 mockups

Twenty marks for BaselineWatch, each shown at display size, in the masthead lockup, at the two favicon sizes, in a browser tab and on an app tile. The accent is the site's own green; ink and accent swap for dark mode inside each SVG, so any of these works as a favicon as it stands. Diff, Tower and Horizon are taken further on the refinements sheet.

How to read a card. The large mark is for the masthead and reports. The two small boxes are the mark at 32 and 16 CSS pixels as your screen draws them; the boxed square beside them is the same 16-pixel icon rasterised once at 1× and blown up four times, which is what a browser tab gets on a plain monitor. If a mark survives that box it survives everywhere.

Wiring a favicon

  • Copy the chosen SVG to public/favicon.svg and add it to the layout head. Firefox and Chromium follow the SVG's prefers-color-scheme rule; Safari ignores SVG favicons, so keep a PNG or ICO beside it.
  • Export a 180 px PNG for apple-touch-icon and a 32 px ICO for the fallback; the mark's ink should be solid on those, not theme-aware.
  • The BoxPilot manifest's icon is an emoji string today (🛡️); the catalog card is a separate question from the favicon.
<link rel="icon" href="/favicon.svg" type="image/svg+xml">
<link rel="icon" href="/favicon.ico" sizes="32x32">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">

Notes

  • All marks sit on a 64-unit grid with strokes of six units or more, so nothing thinner than a pixel and a half reaches the 16 px icon.
  • Marks 09 (Diff) and 20 (Tile) carry a third colour; the rest are ink plus one accent, which also keeps a one-colour print version trivial.
  • Mockup page uses inline styles, a little script for the theme switch and the 1× loupe, and Google Fonts; it is not served by the app, so the app's CSP does not apply.
